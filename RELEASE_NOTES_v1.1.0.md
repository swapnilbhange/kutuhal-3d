# Kutuhal 3D v1.1.0

**Upload a script. Get a finished 3D explainer Short.**
Claude (or another AI coding agent) analyses your script, then generates the narration, a stylised 3D video, music, sound effects and captions, and gives you an MP4.

## Highlights
- **Script → MP4 in one request.** Narration (Kokoro TTS), word-level timing, low-poly three.js 3D scenes, animated overlays, synthesised music (12 moods), ~30 SFX and 6 ambience beds, word-by-word captions, −14 LUFS mastering, SRT export.
- **9:16 or 16:9**, 720p to 4K. Five style presets (midnight, ember, arctic, neon, pastel).
- **Runs on your machine, offline after setup.** No GPU needed; all music and SFX are generated by the code.
- **Five skills:** `make-3d-short` (whole pipeline), `new-short`, `render-short`, `short-sound`, `short-looks`.
- **Complete worked example** (`planning-fallacy`) with a 1080p sample video, contact sheet, style grid, script, captions and shot plan in `samples/`.

## New in 1.1.0
- **Works beyond Claude:** `scripts/install-skills.sh` installs the skills for Claude Code, OpenAI Codex / ChatGPT desktop, Gemini CLI and Google Antigravity.
- **New guides:** `docs/OTHER-AI-TOOLS.md` (per-tool install steps) and `docs/PUBLISHING.md` (put your own copy on GitHub).

## Install

**Claude Code** (run in your own terminal):
```bash
claude plugin marketplace add swapnilbhange/kutuhal-3d
claude plugin install kutuhal-3d@kutuhal-plugins
```
Inside a Claude Code session the same thing is `/plugin marketplace add swapnilbhange/kutuhal-3d` then `/plugin install kutuhal-3d@kutuhal-plugins`.

**Claude desktop app / Cowork / claude.ai:** download `kutuhal-3d.plugin` below → Customize → Plugins → Add → Upload plugin. If the upload is rejected, use `kutuhal-3d.zip` (identical file).

**Codex / ChatGPT desktop, Gemini CLI, Antigravity:** clone the repo and run `bash scripts/install-skills.sh <codex|gemini|antigravity>`. See `docs/OTHER-AI-TOOLS.md`.

Full guide: `docs/INSTALL.md`.

## Requirements
Python ≥ 3.9, Node ≥ 18, ffmpeg, Chrome or Chromium; about 1.5 GB disk; internet on first run (Kokoro voice model ≈ 330 MB). An AI agent that can run shell commands and, ideally, view images.

## Verified
- `claude plugin validate` passes for the marketplace and the plugin.
- Installed from this repository with the Claude Code CLI (`kutuhal-3d@kutuhal-plugins`, version 1.1.0, enabled).
- The installer script places all five skills correctly for every supported tool.
- The bundled example renders from a fresh clone; the sample video was produced end to end by the plugin (1080×1920, 30.4 s, −14.6 LUFS).

## Known limitations
- Tested on **Linux** only. macOS should work; Windows via WSL 2. Native Windows is untested.
- Not yet run inside Codex, ChatGPT, Gemini or Antigravity themselves; their install steps follow each vendor's documented skills format.
- The 3D scenes are written per script by the AI agent, not picked from a template library, so abstract scripts may need a round of "make that shot clearer".
- Software rendering is slow: about 13 minutes for a 30-second 1080p video on 2 CPUs. More cores and `--workers N` speed it up.
- Stylised low-poly look; mouths follow loudness, not exact phonemes. One narrator per video, no voice cloning, English-centric TTS and alignment.
- The `pastel` style expects light scenes and has poor contrast on dark ones.
- The AI agent can't listen to audio; judge the voice and music yourself. Re-mixing takes seconds.
