# Example: planning-fallacy (30 s, 9:16)
A complete, tested project: `input/script.txt` → `story/` → `timeline/` → `scenes/` (cast, props, 2 sets, 8 shot modules). The finished video is in the repository's `samples/` folder.
Use it as the template for new scenes. To re-render: `cp -r examples/planning-fallacy projects/ && node render.mjs --project projects/planning-fallacy && python3 audio/mix.py --project projects/planning-fallacy` (first run `python3 tools/narrate.py --project projects/planning-fallacy` to generate `input/narration.wav`; binary audio and video files are not bundled in the plugin).
