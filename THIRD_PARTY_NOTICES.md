Kutuhal 3D's own code is MIT-licensed (see `LICENSE`). It uses the following components, each under its own licence. Nothing below is modified or redistributed except the Poppins font file, which ships in the kit.

| Component | Used for | Licence | Shipped in this package? |
|---|---|---|---|
| [three.js](https://threejs.org) | 3D rendering | MIT | No – installed by `npm install` |
| [puppeteer-core](https://pptr.dev) | Drives headless Chrome to capture frames | Apache-2.0 | No – `npm install` |
| [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) | Text-to-speech voice model | Apache-2.0 | No – downloaded on first narration |
| [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) | ONNX runtime wrapper for Kokoro | MIT | No – `pip install` |
| [pocketsphinx](https://github.com/cmusphinx/pocketsphinx) | Forced alignment (word timings) | BSD-style | No – `pip install` |
| NumPy, SciPy, SoundFile, Pillow | Audio synthesis, image tools | BSD / HPND | No – `pip install` |
| FFmpeg | Encoding, loudness normalisation, muxing | LGPL/GPL (system install) | No – system package |
| Chrome / Chromium | Headless renderer | BSD-style + others | No – system install |
| [Poppins Bold](https://fonts.google.com/specimen/Poppins) | Caption and overlay font | SIL Open Font License 1.1 | Yes – `kit/assets/fonts/` |

All music, sound effects and ambience are synthesised procedurally by the code in `kit/audio/`; no third-party samples are included.
The sample video and images in `samples/` were generated by this plugin from an original script and are released under the same MIT licence.
